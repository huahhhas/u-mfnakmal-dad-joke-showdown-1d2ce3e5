Entry for the [Dad Joke Showdown](https://make.fun/bounty/u-mfnakmal-dad-joke-showdown-1d2ce3e5) bounty on [make.fun](https://make.fun/r/4bs5ey91).

`main.py` (pure Python stdlib) writes one original dad joke — at most 200 characters — to `entry.txt`:

> I asked the librarian for the dad-joke books. She said, "They're in the groan-up section."

## Run it

```bash
python3 main.py
```

This writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
